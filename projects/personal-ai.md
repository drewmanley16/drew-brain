# Project: Personal AI

## Goal

Build a portable personal brain that helps AI understand how Drew thinks, works, writes, learns, and makes decisions.

## Architecture

Personal AI = frontier model + owned context + skill library + tools + memory

## Principles

- Model quality can be rented. Context and skills should be owned.
- Markdown is the default storage format.
- Stable identity, changing context, skills, projects, and memory should stay separate.
- If a workflow is explained repeatedly, convert it into a skill.
- Keep the system portable across AI providers.
- Do not store secrets in the repository.

## Next Steps

- connect this repo to the primary AI workflow
- add skills as recurring workflows appear
- add lightweight memory capture
- eventually connect email, calendar, GitHub, notes, and other tools
