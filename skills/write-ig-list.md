# Skill: IG List Post

## Purpose
"10/10 X that will Y" format — a numbered/named list of repos, videos, or
tools. E.g. "10/10 GH repos" / "10/10 YT videos to master claude" scripts.

## Before writing
Read `context/content-instagram.md` for voice rules.

## Inputs to identify
- The category (GH repos, YT videos, tools, etc.)
- The outcome promised in the hook ("that will get you hired", "that will
  make you an expert")
- 4-5 specific items with exact names/paths/titles
- CTA word or "follow for more" if no resource to send

## Structure
1. Hook: "[number]/[number] [category] that will [outcome]" — on screen text
   version can repeat with a slight variation.
2. For each item: exact name/path, then one plain-English line on what it is
   and why it's good. No filler between items, no transitions needed.
3. Optionally call out a favorite at the end ("and finally my favorite...")
   to close instead of trailing off.
4. CTA: comment word for the full list, or "follow for more [topic] tips."

## Output
Plain lines, no markdown formatting. Keep each item to exactly 2 lines
(name, then description).
