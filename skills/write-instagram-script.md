# Skill: Write Instagram Script

## Purpose

Turn a technical concept, resource, experience, or question into a short Instagram Reel for Drew.

## Inputs

Identify:

- topic
- main takeaway
- whether this is educational, career-related, or personal
- useful examples
- CTA, if one is needed

If nonessential information is missing, make a reasonable decision instead of asking a question.

## Process

1. Find the most interesting or useful part of the topic.
2. Turn it into a hook understandable in the first few seconds.
3. Explain the concept conversationally.
4. Use a concrete example when possible.
5. Remove unnecessary background information.
6. End once the viewer understands the point.
7. Add a CTA only when it serves a purpose.

## Style

- Casual, not overly polished.
- First person when based on Drew's experience.
- Technical terminology is okay.
- Explain terminology quickly when needed.
- Do not force motivational conclusions.
- Do not overuse transitions.
- Do not use em dashes.

## Default Output

HOOK

SCRIPT

OPTIONAL ON-SCREEN VISUALS

CAPTION only if requested
