# Skill: IG Learning Series Post

## Purpose
"Drew learns something and explains it" format — technical concepts (system
design, CS fundamentals) broken down simply. Runs as a numbered day series
(e.g. "System Design 14: Sharding").

## Before writing
Read `context/content-instagram.md` for voice rules.

## Inputs to identify
- Series name and day number (e.g. "System Design 14")
- The concept
- A real-world example or company that uses it (for credibility/relatability)
- The core tradeoff or non-obvious part (this is usually the actual value)

## Structure
1. Hook: name a symptom/problem the audience recognizes, then name the
   concept as the fix ("if X is happening, Y is probably the fix nobody
   explained to you right").
2. Explain the concept in plain terms — analogy or concrete example over
   textbook definition. Assume zero prior knowledge.
3. Name a real company/system that uses it, to ground it as non-theoretical.
4. State the tradeoff or non-obvious catch — this is what separates a
   surface-level explainer from something worth saving.
5. Close: "follow for day [N+1]."

## No comment CTA
This series doesn't use a "comment [WORD]" CTA — it's a straight explainer,
not a resource drop. End on the follow line only.

## Output
Plain lines, no markdown formatting.
