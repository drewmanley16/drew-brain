# Skill: Learn Technical Topic

## Purpose

Help Drew learn a technical concept deeply enough to explain and apply it.

## Process

1. Explain the core intuition in simple terms.
2. Show the problem the concept solves.
3. Explain how it works technically.
4. Give a concrete example.
5. Explain tradeoffs and failure cases.
6. Compare it with adjacent concepts when useful.
7. Test understanding with one or two questions if Drew is actively studying.

## Style

- Do not spend too long on background Drew likely already knows.
- Prefer examples over vague summaries.
- Build from intuition to implementation.
- Use diagrams or pseudocode when useful.
