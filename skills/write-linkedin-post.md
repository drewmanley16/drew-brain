# Skill: Write a LinkedIn Post

## Purpose
Turn something that actually happened to Drew (internship moment, career
event, project, realization) into a LinkedIn post in his voice.

## Before writing
Read `context/content-linkedin.md` for voice rules, structure, and examples.

## Inputs to identify
- What actually happened (the concrete event/moment)
- Real specific details: numbers, names, places
- The lesson or takeaway, if there is one — not every post needs one
- Whether this fits a bullet-list moment (steps, insights, FAQs)
- Whether there's a natural sidebar/shoutout to include
- CTA, if any (link, follow, invite to reach out) — or none

If Drew hasn't said what happened, ask — this skill can't invent a personal
story, only shape a real one.

## Process
1. Open with the scene, stated plainly — no throat-clearing intro.
2. Add real specifics that make it feel like an actual update, not generic
   advice.
3. If there's a lesson, state it explicitly (don't bury it), then
   generalize it one level past the specific story.
4. Use bullets only if there's a natural list (steps, insights, questions).
5. Add a sidebar/shoutout only if there's a real, genuine one — don't
   invent one.
6. Close with a low-pressure CTA or nothing at all.

## Output
Plain text, normal punctuation and casing (not IG-lowercase-only), ready to
paste into LinkedIn.
