# Skill: Weekly Content Batch

## Purpose
Produce a batch of draft Instagram scripts for the week in one pass, mixing
time-sensitive material with the ongoing series cadence, instead of
generating scripts one at a time on request.

## Before writing
Read `context/content-instagram.md` and `projects/drewisliving.md` (series
tracker) first.

## Inputs to identify
- Default batch size: 3 scripts/week (adjust if Drew asks for more/fewer)
- What's actually live this week:
  - Learning series: next day number (from the series tracker in
    `projects/drewisliving.md` — increment from the last logged day)
  - Internship news: only include if Drew's swelist.com email that day has
    real, recognizable postings worth naming (see
    `skills/write-ig-internship-news.md` for sourcing)
  - Resource drop / list post: only include if Drew has a specific
    resource/list in mind, or asks to fill a slot with one — don't invent
    resources to hit a quota

## Process
1. Check `projects/drewisliving.md` for the current learning-series day
   count. Default to continuing it as one slot in the batch.
2. Pull today's swelist.com email (Gmail, `from:swelist.com`) for a second
   slot if internship season is active and postings are relevant.
3. Ask Drew what fills the remaining slot(s) if nothing else is obviously
   due (resource drop, list post, personal update) — don't fabricate a
   topic just to fill the batch.
4. For each slot, invoke the matching skill:
   - `write-ig-learning-series.md`
   - `write-ig-internship-news.md`
   - `write-ig-resource-drop.md` / `write-ig-list.md` / `write-ig-personal-series.md`
5. Present all drafts together, labeled by format and (for series content)
   day number, so Drew can approve/edit the batch at once instead of
   one-by-one.
6. After Drew approves, update the series day counter in
   `projects/drewisliving.md`.

## Output
Numbered list of scripts, each with a one-line label (format + day number
if applicable), plain-text script below each label.

## Never
Never invent a topic, resource, or company name to fill a batch slot — an
empty slot with a question to Drew is better than a fabricated post.
