# Decisions

## 2026-08-15 — Personal AI Architecture

**Decision:** Use markdown files in a Git repository as the primary personal knowledge base.

**Why:** Markdown is portable, human-readable, version-controlled, easy for agents to edit, and not locked to one model provider.

## 2026-08-15 — Skill Philosophy

**Decision:** Recurring workflows should become skill files instead of increasingly complicated prompts.

**Rule:** If Drew has to explain a workflow more than twice, consider skillifying it.
